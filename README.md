# schedule-bot

Бот: каждый день в беседе VK кидают файл (.docx) с расписанием на следующий день —
бот находит в нём группу студента, дополняет домашкой из ЭлЖура и присылает
расписание вместе со звонками в Telegram. Присылает сам, как появляется новый файл —
каждому, кто выбрал свою группу; плюс команды `/today` и `/tomorrow`. Ботом
пользуются разные студенты: при `/start` выпадает меню со всеми группами из
файла (47 шт.), выбор запоминается.

## Как это работает

1. Служебный цикл раз в `VK_CHECK_INTERVAL` секунд смотрит беседу VK (юзер-токен),
   забирает самый свежий `.docx`.
2. Парсер вытаскивает из таблицы строки группы студента и дату из имени файла
   (`09.docx` → 9-е число; `Пт_06.docx`, `расписание_Чт_10нед_05.docx` тоже понимает).
3. Если настроен ЭлЖур — на эту дату подтягивается ДЗ и подписывается под предметы
   (названия в расписании и в журнале часто не совпадают дословно, поэтому
   сопоставление нестрогое: по коду МДК, по совпадению слов). ДЗ показывается
   только владельцу бота (`CHAT_ID`) — учётка ЭлЖура личная.
4. Текст уходит в Telegram: пары + ДЗ + звонки. В блоке звонков — **только пары
   этого дня по графику на его день недели** (пн / вт-пт / сб из `bells.json`):
   кому первая пара с 3-й, не видит, когда кончается 1-я.

## Установка

```bash
cd schedule_bot
pip install -e .        # или: pip install aiogram pydantic-settings python-docx requests beautifulsoup4
copy .env.example .env  # и заполнить
python main.py
```

## Заполнение .env

| Переменная | Откуда взять |
|---|---|
| `BOT_TOKEN` | [@BotFather](https://t.me/BotFather) → `/newbot` |
| `CHAT_ID` | твой telegram id (у [@userinfobot](https://t.me/userinfobot)) |
| `GROUP` | не обязательно: твоя группа для авто-пуша (по умолчанию `2025-ТНГ-96Д`); на меню групп не влияет |
| `VK_TOKEN` | юзер-токен с правами `messages` (см. ниже) |
| `VK_CHAT_PEER_ID` | `2000000000 + номер чата`; узнать: `python tools/vk_chats.py` |
| `ELJUR_URL` | адрес журнала вида `https://school.eljur.ru` |
| `ELJUR_LOGIN` / `ELJUR_PASSWORD` | учётка ученика в ЭлЖуре |

### VK-токен

Нужен пользовательский токен с доступом к сообщениям (`messages`).
Проще всего получить через генераторы токенов на базе приложений VK
(например Kate Mobile / VK Admin, см. `vkhost.github.io`) — токен вида
`vk1.a.XXXX...`. Вход логином/паролем через API VK сегодня почти всегда
ловит капчу/флуд-контроль, поэтому токен достаётся вручную.

Проверка, что токен и беседа найдены: `python tools/vk_chats.py`.

### Прокси для Telegram

Если `api.telegram.org` недоступен напрямую (провайдер режет), бот ходит
в Telegram через прокси из `TG_PROXY` — VPN для этого включать не нужно.
У Happ (Proxy Utility) есть встроенный SOCKS5: в настройках включить
**«SOCKS5 proxy» / «SOCKS5 proxy port»**, Happ держать подключённым
к серверу — TUN можно не включать, через прокси пойдёт только бот.
Порт смотрите сами (в разных сборках 1080/10808) — `netstat -ano | findstr LISTENING`.

```bash
python tools/tg_check.py          # проверить связь (getMe)
python tools/tg_check.py --send   # и отправить тестовое сообщение
```

### ЭлЖур

Бот заходит в веб-версию журнала как обычный пользователь (`/ajaxauthorize`)
и читает страницы дневника по неделям. От школы нужны только URL и учётка.
Если у школы нестандартный вход (ССО/ЕСИА) — вход не сработает, напиши —
добавлю вариант. ДЗ ставится в тот день, к которому его нужно сдать
(так устроен журнал), поэтому оно подписывается под пары своего дня.

## Расписание звонков

Файл `bells.json` — три графика: `monday` (с «Разговорами о важном»), `tue_fri`,
`saturday`. График выбирается по дню недели даты расписания. Правь под свой колледж:

```json
"monday": {
  "talks": { "start": "08:00", "end": "08:30", "title": "Разговоры о важном" },
  "4": { "start": "14:10", "end": "15:40" }
}
```

В сообщении показываются только звонки по числу пар студента (плюс «Разговоры»,
если они в этот день есть). Диапазоны пар (`3-4 п.`) берут начало первой и конец последней.

## Утилиты

python tools/render.py путь\к\09.docx   # как выглядит сообщение из локального файла

## Команды бота

- `/start` — меню выбора группы (все группы из файла расписания)
- `/group` — сменить группу
- `/today` — расписание на сегодня (если файл на этот день уже кидали)
- `/tomorrow` — расписание на завтра

Как только в беседе появляется новый `.docx`, расписание приходит само всем,
кто выбрал группу через `/start` — каждому по его группе. Владельцу (`CHAT_ID`)
оно идёт с ДЗ из ЭлЖура (учётка личная).

## Хостинг на GitHub Actions (бесплатно)

Бот умеет работать «пачками» по крону GitHub Actions: каждые 2 минуты запускается
`runner.py` — забирает команды Telegram, отвечает, проверяет беседу VK. Задержка
ответа — до ~2–3 минут. Плата не нужна; репозиторий должен быть **публичным**
(на приватных Actions даёт только 2000 минут/мес — не хватит).

Перенос:

1. Залей проект в публичный GitHub-репозиторий (секреты не попадут — `.env` в `.gitignore`).
2. В настройках репозитория **Settings → Secrets and variables → Actions** добавь секреты:

   `BOT_TOKEN`, `CHAT_ID`, `VK_TOKEN`, `VK_CHAT_PEER_ID`,
   `STATE_KEY` (любая длинная фраза для шифрования состояния),
   по желанию `GROUP` (твоя группа для авто-пуша; на меню групп не влияет)
   и `ELJUR_URL`, `ELJUR_LOGIN`, `ELJUR_PASSWORD`.

   `TG_PROXY` в облаке не нужен — GitHub-раннеры ходят в Telegram напрямую.
3. Actions включён автоматически при наличии `.github/workflows/bot.yml`; первый
   прогон — вкладка Actions → schedule-bot → Run workflow.
4. **Локального бота (`python main.py`) останови** — два поллера одного бота дают
   Telegram Conflict.

Состояние (кто какую группу выбрал, offset Telegram) хранится в `state.json.enc`
в том же репозитории — файл зашифрован секретом `STATE_KEY`.

Если нужен «живой» бот без задержек — запускай `python main.py` на VPS или у себя
(тогда workflow отключи).

## Структура

```
main.py            запуск бота + слежения (живой режим, long polling)
runner.py          один прогон для GitHub Actions (по крону)
watcher.py         проверка беседы VK
config.py          настройки из .env / переменных окружения
bells.json         звонки (пн / вт-пт / сб)
.github/workflows/bot.yml  крон-workflow для Actions
bot/handlers.py    команды Telegram + меню групп
services/
  parser.py        .docx -> занятия группы
  vk_source.py     забор файла из беседы
  eljur.py         ДЗ из ЭлЖура + сопоставление с парами
  formatter.py     текст сообщения
  pipeline.py      общий конвейер
  bells.py, models.py, state.py
tools/             render.py, vk_chats.py
```
